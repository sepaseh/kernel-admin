# Kernel Admin

[English](README.md) · [فارسی](README.fa.md)

انتشار `assistant-guidance`، [راهنمای محلی توسعه](docs/README.fa.md)، قواعد و skillهای مرجع انگلیسی، نقشهٔ ماشینی وظیفه و روش ارزیابی فقط خواندنی را نیز اضافه می‌کند. hook اختیاری و آداپتور میزبان، وابستگی برنامه یا شاهد بارگذاری خودکار نیستند.

Kernel Admin یک برنامهٔ مستقل TypeScript با React/Vite، Ant Design/antd-style، React Router و Axios است. مرحلهٔ فعلی **application-verification**، src/main.tsx، ترکیب App و Routes و دروازهٔ واقعی برنامه را در کنار ماژول‌های منتشرشده و محیط مستقل Storybook می‌پذیرد. مقدار `applicationReady` و فهرست دقیق منبع پذیرفته‌شده را از [سیاست انتشار](.github/bootstrap-policy.json) بخوانید؛ اعلام قابلیت جای بررسی واقعی را نمی‌گیرد.

[زیرساخت رابط کاربری](docs/ui-foundation.fa.md) مالکیت مؤلفه، پوسته، ترجیحات و دارایی‌ها و محدودیت آزمون‌های آن‌ها را توضیح می‌دهد.

## محدودهٔ فعلی

- [وضعیت توکن](src/shared/api/token.ts) توکن دسترسی را در حافظه نگه می‌دارد و نسل
  ورود و خروج را از نوسازی توکن جدا می‌کند.
- [تایپ انتقال](src/shared/api/types.ts) و
  [محدودیت مشترک نام پروفایل](src/shared/contracts/index.ts) قراردادهای کوچک محلی را
  تعریف می‌کنند.
- [تبدیل کلیدها](src/shared/lib/transform.ts) کلید داده‌های تودرتوی سادهٔ HTTP را
  بین camel case و snake case تبدیل می‌کند.
- [ابزارهای کنتراست](src/shared/lib/color-contrast.ts) رنگ خوانای نمایش را بدون
  تغییر انتخاب ذخیره‌شدهٔ پوسته محاسبه می‌کنند.
- [کاتالوگ‌ها](src/shared/i18n/catalogs.ts) برای هرکدام از ده
  [کد محلی](src/shared/i18n/locales.ts) یک شیء کامل و تخت با ۱۱۱ پیام ریشه ثبت می‌کنند.
  [دادهٔ تقویم فارسی](src/shared/i18n/dayjs/fa.ts) از پیام‌های رابط کاربری جداست.
  مالکیت و بررسی‌های درستی در [راهنمای بومی‌سازی](docs/localization.fa.md) آمده‌اند.

- [کلاینت و مالکیت HTTP](docs/http-client.fa.md) نسل نشست و اعتبارسنجی توکن و تنظیمات سرور را اضافه می‌کند.
- [هوک‌های چرخهٔ درخواست](docs/request-lifecycle.fa.md) کار قدیمی را لغو و دادهٔ پذیرفته‌شده را هنگام خطای نوسازی حفظ می‌کنند.
- [واژگان ظاهر](src/shared/contracts/appearance.ts) مالک Theme و هفت فیلد پالت است و Ant Design را راه‌اندازی نمی‌کند.
- [صفحه‌های مدیریتی](docs/business-screens.fa.md) ماژول‌های حساب، کاربران، نقش‌ها، تنظیمات و تقویم را با تغییر دادهٔ محافظت‌شده اضافه می‌کند؛ داشبورد فعلاً قاب چیدمان است.
- [Core و احراز هویت](docs/core-auth.fa.md) چرخهٔ ارائه‌دهنده‌ها، تنظیمات متعلق به سرور، فرم‌های محافظ نشست، فرادادهٔ دسترسی و مالکیت چیدمان را توضیح می‌دهد.
- [اعتبارسنجی Storybook](docs/storybook-verification.fa.md) مالک storyهای جداگانه، mock کامل API ساختگی، کنترل زبان و جهت و پوسته و بررسی الزامی مرورگر است.

تبدیل کلیدها نام کلیدهای شیء ساده را تغییر می‌دهد و فیلدهای با مقدار null را حذف
می‌کند. نتیجه از نوع `unknown` است؛ پیش از استفاده، آن را اعتبارسنجی و به قرارداد
HTTP مورد انتظار محدود کنید. مقادیر غیرساده هویت خود را در زمان اجرا حفظ می‌کنند،
اما نوع آن‌ها نیز به بررسی و محدودسازی نیاز دارد. کلاینت HTTP شکل DTO عادی را فقط در مرز قرارداد فرض می‌کند؛ توکن و تنظیمات حساس در زمان اجرا اعتبارسنجی می‌شوند. تبدیل کلیدها نوع جنریک را ثابت نمی‌کند.

ابزار کنتراست رنگ‌های hex و قالب کامادار `rgb()` و `rgba()` را با کانال‌های ۰ تا ۲۵۵
و آلفای ۰ تا ۱ می‌پذیرد؛ ورودی پشتیبانی‌نشده یا نامعتبر خطای `TypeError` می‌دهد.
تنظیم رنگ نمایش، تمام سایه‌های گرد‌شده در مسیر ترکیب به سمت سیاه و سفید را بررسی
می‌کند و تا جای ممکن فام انتخاب‌شده را اضافه می‌کند. اگر هیچ‌کدام از این دو مسیر
کنتراست مورد نیاز همهٔ سطوح را تأمین نکند، بهترین سایهٔ موجود در همین مسیرها برگردانده
می‌شود.

مرحلهٔ فعلی کاتالوگ‌های کامل، راه‌انداز واقعی i18next/react-i18next با React و ثبت تقویم‌های Day.js/Jalaliday را منتشر می‌کند. راه‌اندازی ترجمه همیشه فارسی است و زبان بازدیدکننده از حافظهٔ مرورگر خوانده یا در آن ذخیره نمی‌شود. ثبت تاریخ از نه زبان کتابخانه و دادهٔ محلی فارسی استفاده می‌کند؛ انگلیسی با نام فروشندهٔ en-gb ثبت می‌شود و انتخاب تقویم میلادی یا جلالی صریح است. تبدیل کد زبان فقط کاتالوگ را انتخاب می‌کند و جهت یا تقویم را تعیین نمی‌کند. تابع پیام خطا، پیام Error را نگه می‌دارد و برای سایر مقادیر از ترجمهٔ محلی استفاده می‌کند. تست‌های ارائه‌دهنده، فرم، چیدمان، مؤلفه و هوک از MSW و jsdom ساختگی استفاده می‌کنند؛ این آزمون‌ها اتصال API عملیاتی را ثابت نمی‌کنند. آزمون مستقل Storybook در Chromium حفظ می‌شود. راه‌اندازی برنامه در [src/main.tsx](src/main.tsx)، [App](src/app/App.tsx) و [Routes](src/app/Routes.tsx) است؛ fixture مرورگر برنامه HTTP ساختگی دارد و درخواست غیرمنتظره را رد می‌کند.
احراز هویت، دیتابیس، ذخیره‌سازی، زبان فعال، جهت و تقویم بر عهدهٔ API مستقل است.

## نصب و اعتبارسنجی

از نسخهٔ Node.js ثبت‌شده در [`.nvmrc`](.nvmrc)، محدودهٔ پشتیبانی‌شده در
[`package.json`](package.json) و npm همراه همان نسخهٔ Node.js استفاده کنید.

```sh
npm ci
npm run browser:install
npm run validate -- full
```

[فهرست اعتبارسنجی](.agents/validation.json) مالک بررسی الزامی محلی و PR، سازگاری کامل و پروفایل گزارش‌دهندهٔ کارایی است. پروفایل هفده‌ورودی `full` تایپ، lint، قالب‌بندی، ممیزی، مرزها، پوشش واقعی واحد و governance، تعامل و دسترس‌پذیری Storybook، ساخت production و بودجهٔ حجم، قرارداد و مسیرهای Chromium را حفظ می‌کند. بررسی کامل، چهار پروژهٔ مرورگر را جایگزین و تصاویر تأییدشده را یک بار مقایسه می‌کند. بررسی کد محلی به نسخهٔ Windows تصاویر CI وابسته نیست. تست‌ها ساختگی‌اند و محیط اپراتور یا API واقعی نمی‌خواهند.

دو اجرای تست، گزارش‌های واقعی `coverage/unit/lcov.info` و
`coverage/governance/lcov.info` را از همین نسخه تولید می‌کنند. این گزارش‌ها ابزارهای
پایهٔ منتشرشده، ارائه‌دهنده‌ها، فرم‌ها، چیدمان‌ها، فرادادهٔ دسترسی، HTTP، چرخهٔ درخواست، کاتالوگ‌ها، راه‌اندازهای اجرایی، دادهٔ تقویم و ابزارهای مخزن را پوشش می‌دهند و پوشش کامل پنل نیستند. خروجی‌های
تولیدشده کامیت نمی‌شوند. خروجی ساخت Storybook و نتیجهٔ مرورگر جای این گزارش‌های
اندازه‌گیری‌شده را نمی‌گیرند. [راهنمای Sonar](docs/sonarqube.fa.md) را ببینید.

## مشارکت

[راهنمای مشارکت](CONTRIBUTING.fa.md) و
[راهنمای انتشار](docs/bootstrap.fa.md) را بخوانید. هر PR باید حداکثر
**۱۰۰ ورودی فایل تغییرکرده در GitHub** داشته باشد و همان نسخهٔ پیشنهادی بررسی شود.

از CI، CodeRabbit و SonarQube Cloud همراه [حفاظت شاخه](docs/branch-protection.fa.md) استفاده کنید. تنظیمات، اجرای میزبانی‌شده نیست. CI هر مجموعهٔ مرتبط را برای head و مبنا و درخت ادغام یک بار اجرا و پوشش تأییدشده را به scanner واقعی می‌دهد. نتیجهٔ موفق بررسی الزامی نسخهٔ فعلی، تأیید و حل گفت‌وگوها حفظ شود. تغییر حفاظت راه‌دور همچنان مجوز می‌خواهد؛ تغییر منبع به‌تنهایی آن را نصب نمی‌کند.

## پیش‌نیازهای عملیات و کیفیت

نمونهٔ عمومی، ابزار استقرار و نسخه، سیاست خالص کیفیت و [راهنمای عملیات](docs/deployment.fa.md) پیشین منتشرشده باقی می‌مانند. [فهرست دقیق](.github/bootstrap-policy.json) مسیرهای نگهداری‌شده را اعلام می‌کند؛ این تعداد با تعداد فایل‌های تغییرکردهٔ PR تفاوت دارد.

رگرسیون ابزارهای تازه وارد همان پوشش واحد و governance موجود می‌شود. ورودی صریح و ساختگی و مدیریت خطای منابع متعلق به آزمون را بررسی می‌کند؛ Docker یا Chrome راه نمی‌اندازد، پنل نمی‌سازد و به API مستقر وصل نمی‌شود. [سیاست کارایی](docs/performance.fa.md)، [آماده‌سازی قرارداد](docs/contract-testing.fa.md) و [بازبینی امنیت](docs/security/reviews.fa.md) دامنهٔ واقعی خود را شرح می‌دهند. چهار PNG و فرادادهٔ Windows فقط [سابقهٔ تاریخ‌دار](docs/visual-regression.fa.md) هستند، نه تأیید تازهٔ baseline.

انتشار سورس مجوز فرمان استقرار یا اپراتور نیست. محیط واقعی، گواهی، دادهٔ API و وضعیت اپراتور خارج بررسی منبع می‌مانند. برای بررسی الزامی کد، تصویر میزبانی‌شده و سازگاری کامل از فهرست مرجع پیروی و استثنای زمان‌دار Lighthouse را جدا ثبت کنید. بررسی ارائه‌دهنده، Docker، mutation، staging و استقرار به منبع پذیرفته‌شده و مجوز و شاهد واقعی نیاز دارد.
