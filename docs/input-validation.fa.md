# اعتبارسنجی ورودی پنل

[English](input-validation.md) · [فارسی](input-validation.fa.md)

profileNameMaxLength ماژول محلی src/shared/contracts را در فرم حساب، ثبت‌نام و مدیریت بازاستفاده کنید. adapter موجود snake_case و پاسخ اختیاری یا nullable را در مرز نرمال می‌کند. اعتبارسنجی کلاینت بازخورد را بهتر می‌کند؛ API مستقل نوع، محدودیت، مجوز و شرط تراکنش را می‌سنجد.

نام اختیاری حذف‌شده یا خالی مقدار سرور را حفظ می‌کند؛ نوع اشتباه یا مقدار بیش‌ازحد پیش از نوشتن در API رد می‌شود. الزام ساخت حساب و سیاست رمز رفتار موجود را حفظ می‌کند. موتور اعتبارسنجی فقط فرانت‌اند اضافه نکنید و از کنترل غیرفعال، مجوز سرور نتیجه نگیرید.

آزمون واقعی فرم React و Ant Design در jsdom جداگانه، اعتبارسنجی محلی و کنترل صفحه‌کلید را بررسی می‌کند. آزمون API قابلیت، رفتار HTTP ساختگی را می‌سنجد. Pact و اعتبارسنجی مرورگر متعلق به دروازهٔ برنامهٔ اجرایی آینده‌اند و شاهد این مرحله نیستند. [صفحه‌های مدیریتی](business-screens.fa.md) را ببینید.
