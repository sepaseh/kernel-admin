# دامنهٔ انتشار برنامه

[English](bootstrap.md) · [فارسی](bootstrap.fa.md)

مرحلهٔ application-verification در [سیاست انتشار](../.github/bootstrap-policy.json) مقدار applicationReady: true را اعلام می‌کند. src/main.tsx، ترکیب App/Routes و پیکربندی Vite، ساخت، مرورگر و قرارداد همراه تمام ماژول‌های پیشین HTTP، کاتالوگ، provider، کسب‌وکار و Storybook پذیرفته می‌شوند. API مستقل بیرون این ریپو می‌ماند. اعلام مرحله فقط دامنهٔ سورس پذیرفته‌شده است؛ اجرا، تأیید تصویری و استقرار باید جدا ثبت شوند.

فهرست دقیق، سورس اعلام‌نشده، فایل الزامی مفقود، مسیر خصوصی و لینک نمادین را رد می‌کند. اندازهٔ آن با سقف ۱۰۰ فایل تغییر واقعی هر PR مستقل است. node_modules و coverage و dist برنامه در ریشه، خروجی تولیدی‌اند و فایل انتشار نیستند. بایت‌ها و تاریخ بازبینی تصاویر تاریخی Win32 حفظ می‌شوند. تصاویر مقایسهٔ جدید باید منشأ منطبق و بازبینی انسانی واقعی خود را داشته باشند.

[فهرست مرجع](../.agents/validation.json)، [.nvmrc](../.nvmrc) و npm همراه آن را به کار ببرید. در خروجی مستقل تازه از درخت نهایی دقیق، npm ci، npm run browser:install و npm run validate -- full را اجرا کنید. هر نوزده بررسی الزامی بدون انتخاب بر اساس مسیر، تکرار، جایگزینی advisory یا تضعیف آستانه اجرا می‌شود. هر دو گزارش LCOV اندازه‌گیری‌شده باید متعلق به همین snapshot باشند.

CI و scanner پس از نصب، همان فرمان کامل و بدون شرط را اجرا می‌کنند. jobهای Windows با نام check/build/e2e/visual فرمان واقعی و checkout و Node پین‌شده دارند؛ checkout باید نسخهٔ پیش‌فرض PR را حفظ کند. تحلیل scanner پس از دروازهٔ کامل انجام می‌شود و دروازهٔ کیفیت ناهم‌زمان سرویس شاهد جداست. پیش از تغییر contextهای الزامی راه دور، [حفاظت شاخه](branch-protection.fa.md) را بخوانید؛ تنظیم سورس به‌تنهایی حفاظت را نصب نمی‌کند.

fixtureهای E2E و قرارداد مصرف‌کننده از HTTP ساختگی و فرایندها، پورت‌ها و خروجی‌های متعلق به خود استفاده می‌کنند. این‌ها تأیید API-provider یا مجوز ترافیک production نیستند. مقایسهٔ تصویری به تصاویر تأییدشدهٔ واقعی انسان برای محیط و سورس دقیق نیاز دارد. Lighthouse صفحهٔ احراز هویت ساختگی مستقل را اندازه می‌گیرد. [استقرار](deployment.fa.md)، TLS، smoke مقصد و workflowهای مستقل عملیات، کار مجاز جدا هستند.

[مشارکت](../CONTRIBUTING.fa.md)، [اعتبارسنجی](validation.fa.md)، [آزمون](testing.fa.md)، [معماری](architecture.fa.md) و [نقشهٔ سورس](source-navigation.fa.md) را بخوانید. تأیید CodeRabbit روی head جاری، مکالمات حل‌شده، بررسی‌های native و گزارش کامل Sonar با صفر مسئلهٔ حل‌نشده همچنان شرط ادغام‌اند.
