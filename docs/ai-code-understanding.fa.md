# زیرساخت درک مستقل از دستیار

[English](ai-code-understanding.md) · [فارسی](ai-code-understanding.fa.md)

مرحلهٔ `assistant-guidance` قواعد و skillهای مرجع انگلیسی، ورودی AGENTS، نقشهٔ ماشینی وظیفه، بررسی هماهنگی اعتبارسنجی و تنظیمات و CI همراه تست، تصمیم متصل به منبع و روش ارزیابی فقط خواندنی را منتشر می‌کند. راهنمای انسانی همراه کامل انگلیسی و فارسی دارد؛ دستور فعال دستیار و prompt ارزیابی فقط انگلیسی است. زمان اجرای هوش مصنوعی، پایگاه برداری، indexer یا وابستگی ابری به برنامه اضافه نمی‌شود.

محصول، محیط مؤلفهٔ غیرقابل اجرا با `applicationReady: false` باقی می‌ماند. مسیریابی به مالکان فعلی ارائه‌دهنده‌ها، HTTP و چرخهٔ درخواست، کاتالوگ تخت محلی، فرم، چیدمان، ابزارک و شاهد ساختگی Storybook اشاره دارد. ترکیب App و Routes، E2E کامل برنامه و اجرای واقعی استقرار و تصویر و کارایی کار آینده‌اند؛ پیش‌نیازهای عمومیِ محدود اکنون منتشر شده‌اند.

از جست‌وجوی هدفمند و منبع، قرارداد و تست مالک استفاده کنید. نقشهٔ ایستا، مجوز، وضعیت واقعی نشست یا رفتار تراکنش را ثابت نمی‌کند. موفقیت بررسی هماهنگی شاهد بارگذاری دستور توسط میزبان، فهم آن توسط دستیار یا بهترشدن کارایی با راهنما نیست. نسخهٔ منبع، اثرانگشت منبع منتشرنشده و عدم قطعیت را روشن نگه دارید.

hook اختیاری Node/Bash و آداپتور میزبان به پشتیبانی واقعی میزبان نیاز دارد. ابزار توسعه است و وابستگی اجرا یا مرز اعطای مجوز نیست. دستور کاربر و مجوز موجود کار را تعیین می‌کنند. ابزار جست‌وجو یا گراف به نیاز مشخص، دسترسی و سود اندازه‌گیری‌شده نیاز دارد. از [روش ارزیابی](comprehension-evaluation.fa.md) استفاده و نتیجهٔ واقعی را ثبت کنید؛ سناریوی تنظیم‌شده، آزمایش انجام‌شده نیست.

نقشهٔ وظیفه اکنون ابزارهای عمومی نسخه و استقرار و سیاست خالص کیفیت را نیز معرفی می‌کند. رگرسیون ساختگی آن‌ها وارد مجموعه‌های پوشش موجود می‌شود و سرویس runtime، فرمان npm عملیاتی یا بررسی کامل تازه اضافه نمی‌کند. [آماده‌سازی استقرار](deployment.fa.md)، [سیاست کارایی](performance.fa.md) و [سابقهٔ تصویری](visual-regression.fa.md) حدود را توضیح می‌دهند. نمونهٔ عمومی منبع ساختگی صریح است، نه مجوز خواندن محیط واقعی. فرادادهٔ تاریخ‌دار تصویر، سابقه است و اجرای فعلی یا شاهد درک دستیار نیست. ابزار مقدماتی اکنون منتشر شده؛ اجرای واقعی استقرار و تصویر و کارایی، مانند ترکیب App و Routes و E2E کل برنامه، کار آینده می‌ماند.
