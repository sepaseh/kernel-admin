# زیرساخت رابط کاربری

[English](ui-foundation.md) · [فارسی](ui-foundation.fa.md)

این زیرساخت مالک مؤلفه‌های بازاستفاده‌پذیر Ant Design، ترجیحات پوسته و فشردگی، رفتار بازگشت مسیر، دارایی‌های محلی و آداپترهای اختیاری گزارش خطا و کارایی است. ارائه‌دهنده‌های Core، ماژول‌های مدیریتی و ساخت و بررسی مرورگرِ جداگانهٔ Storybook بر همین مالکیت بنا می‌شوند.

مرحلهٔ فعلی، ترکیب مجاز و `applicationReady` را از [سیاست انتشار](../.github/bootstrap-policy.json) و شاهد الزامی را از [دروازهٔ کامل](../.agents/validation.json) بخوانید. تا وقتی آمادگی false است، تست ماژول و محیط مؤلفه پنل قابل‌اجرا را اثبات نمی‌کند. پذیرش برنامه به بررسی واقعی ساخت، مرورگر و تصاویر بازبینی‌شدهٔ انسانی نیاز دارد؛ مالکیت رابط کاربری تغییر نمی‌کند.

[قرارداد ظاهر](../src/shared/contracts/appearance.ts) تنها مالک Theme، هفت فیلد
پالت و نوع‌های مشتق‌شدهٔ تبادل داده است. راه‌انداز Ant Design همین واژگان را مصرف
می‌کند و توکن‌های نمایشی خوانا می‌سازد؛ قرارداد را تکرار نمی‌کند و مشخصات زبان سرور
را حدس نمی‌زند. فقط فشردگی و پوسته در حافظهٔ مرورگر نگهداری می‌شوند. زبان فعال،
جهت، تقویم و نام‌ها همچنان متعلق به API هستند و ترجیح زبان بازدیدکننده نداریم.
دریافت‌کنندهٔ ترجیح محلی فقط dark و light و مقدار واقعی boolean را می‌پذیرد؛ دادهٔ
محلی خراب پیش از مصرف با مقدار پیش‌فرض امن جایگزین می‌شود.
دسترسی ممنوع به حافظهٔ مرورگر نیز مقدار پیش‌فرض امن می‌دهد. ذخیره‌سازی ناموفق با
هشدار پایان می‌یابد و اجرای فراخوان را متوقف نمی‌کند؛ سریال‌سازی نامعتبر همچنان
خطا می‌دهد.

مؤلفه‌ها نوع props نام‌دار و اعلان نام‌دار `FC<Props>` با import صرفاً نوع از React دارند. مؤلفه‌های عمومی شامل
ورودی رقم و OTP، تأیید رمز، کشوی فرم، بازخورد درخواست، بارگذاری و مرز خطای React
هستند. کنترل واقعی Ant Design و برچسب معنادار را نگه دارید. هوک بازگشت از React Router
استفاده می‌کند و مسیر برنامه تعریف نمی‌کند. قواعد بررسی‌شدهٔ هویت منبع ثبت‌شده و
نسل نشست در [چرخهٔ درخواست](request-lifecycle.fa.md) حفظ می‌شوند.
ورودی رقم در هر دو حالت مدیریت مقدار توسط والد یا خود مؤلفه، فقط رقم نمایش می‌دهد
و مشخصات رویداد تغییر Ant Design را برای فرم مصرف‌کننده نگه می‌دارد.
اگر ورودی OTP صریحاً الزامی باشد، توضیح دسترس‌پذیر ترجمه‌شده به راهنمای موجود
اضافه می‌شود؛ `aria-required` ناسازگار روی گروه قرار نمی‌گیرد. ورودی‌های واقعی،
رفتار مقدار و دیگر مشخصات دسترس‌پذیری حفظ می‌شوند. بازخورد درخواست، خطای همگام یا
ردشدن ناهمگام فراخوان تلاش دوباره را مدیریت می‌کند و پیام خطا و امکان تلاش دوباره
را نگه می‌دارد.

گزارش اختیاری خطا و کارایی مقصد صریح یا دریافت‌کنندهٔ تزریق‌شده دارد. فیلدهای حساس
را پاک‌سازی می‌کند و Web Vitals استاندارد را بدون شناسهٔ معیار، URL یا دادهٔ DOM
گزارش می‌دهد. تست‌ها مقصد ساختگی دارند، فایل محیطی را کشف نمی‌کنند و مقصد گزارش را
خالی می‌گذارند. mock ثبت observer رفتار callback را می‌سنجد و شاهد کارایی مرورگر
واقعی یا کاربران نیست.
بررسی داده‌های همراه خطا محدود است و ارجاع‌های حلقوی را بدون اجرای getter مدیریت
می‌کند؛ خطای گزارشگر نمی‌تواند جای خطای اصلی برنامه را بگیرد.

Vazirmatn با مجوز اصلی SIL Open Font License در خود پروژه نگهداری می‌شود. تست واحد
الزامی، بایت واقعی WOFF2 را با Fontkit مخصوص توسعه باز می‌کند و خانواده، مشخصات محور
وزن ۱۰۰ تا ۹۰۰، نگاشت نویسه‌های فارسی و لاتین و شکل حروف وزن پیش‌فرض را بررسی می‌کند.
هویت مجوز، هش دقیق، ارجاع فونت CSS و SVG مستقل و بدون محتوای اجرایی نیز بررسی می‌شوند.
سبک‌ها نشانگر واضح صفحه‌کلید و کاهش حرکت را حفظ می‌کنند. این بررسی‌ها بارگذاری فونت
در مرورگر یا تغییر شکل همهٔ وزن‌ها را اثبات نمی‌کنند؛ مسیر واقعی بارگذاری فونت در
مرورگر بخشی از گیت بعدی پنل قابل اجراست.

قواعد کاهش حرکت به `#root` پنل یا `#storybook-root` نیاز دارند، پیمایش سند و
پنجره‌های شناور بیرون از آن ریشه را هم پوشش می‌دهند و با تغییر ترجیح سیستم به‌روز
می‌شوند. اولویت انتخابگر ریشه بر کلاس‌های حرکت Ant Design غلبه می‌کند و به اعلان
`!important` نیاز ندارد.

تمام [بررسی‌های مرجع](../.agents/validation.json) روی هر PR الزامی‌اند و همهٔ
ماژول‌های منتشرشدهٔ محصول در پوشش اندازه‌گیری‌شده قرار دارند. تست React و jsdom،
رفتار مؤلفه و بازخورد راست‌به‌چپ، کنتراست پوسته، ترجیحات محلی و هوک مسیر را می‌سنجد.
گیت کامل اکنون ساخت Storybook و بررسی مرورگر و دسترس‌پذیری را هم الزامی می‌کند.
نتیجهٔ ایستا، jsdom یا مرورگر مؤلفهٔ جداگانه جای گیت نوزده‌مرحله‌ای بعدی برنامه،
ساخت پنل محصول، E2E کامل و بررسی تصویری را نمی‌گیرد.
