# سیاست اعتبارسنجی مرجع

[English](validation.md) · [فارسی](validation.fa.md)

[فهرست مرجع](../.agents/validation.json) مالک شناسه، دستور، نوع، محدوده، کار CI و پروفایل بررسی‌هاست. مرحلهٔ `assistant-guidance` مقدار `applicationReady: false` و همهٔ بررسی‌های محیط مؤلفه را نگه می‌دارد و بررسی الزامی راهنما را اضافه می‌کند. تنظیمات، `full` را با همان ترتیب بازتاب می‌دهند؛ بررسی راهنما این بازتاب، مسیرهای مسیریابی و ارزیابی، پیوند دستورها و Markdown نگهداری‌شده را می‌سنجد. CI با نگهبان معنایی موجود بررسی می‌شود و لازم نیست هر دستور داخلی گام مستقل YAML باشد.

از کوچک‌ترین بررسی مرتبط شروع کنید. `npm run validate -- guidance` و `npm run test:guidance` ابزار توسعهٔ متمرکز هستند. پیش از هر commit یا تحویل PR با اجازهٔ صریح، درخت دقیق پیشنهادی Git را در پوشهٔ مستقل و تازه صادر و اجرا کنید:

```sh
npm ci
npm run browser:install
npm run validate -- full
```

از نسخهٔ Node در [`.nvmrc`](../.nvmrc) و npm همراه آن استفاده کنید. پروفایل کامل هر بررسی الزامی را یک بار اجرا می‌کند و با شکست می‌ایستد؛ ورودی ناشناخته، حذف‌شده، تکراری یا اختیاری جای دستور الزامی را نمی‌گیرد. شکست یا نبود audit، شکست است. CI و scanner هر دو نصب وابستگی، نصب Chromium و همان دستور کامل بدون شرط را در ریشه اجرا می‌کنند. نتیجهٔ واقعی head فعلی را جدا از تنظیمات بررسی کنید.

تست واحد، `coverage/unit/lcov.info` می‌سازد؛ تست راهبری Node شامل تست راهنما و hook ایمنی قابل حمل است و `coverage/governance/lcov.info` می‌سازد. موارد wrapper در Bash هنگام وجود Bash قابل استفاده اجرا می‌شوند و در غیر این صورت کنارگذاری اختیاری را گزارش می‌کنند؛ تست ایمنی Node قابل حمل الزامی می‌ماند. قالب‌بند اختیاری پس از ویرایش، ورودی را با Node می‌خواند و با CLI محلی ESLint فقط فایل انتخاب‌شده را اصلاح می‌کند؛ تست موقت آن، دست‌نخوردن فایل‌های نامرتبط را هم بررسی می‌کند. نتیجه و پیش‌نیاز در دسترس نبوده را دقیق گزارش کنید و کنارگذاری را موفقیت ننامید.

هوک اختیاری ایمنی، زیرمجموعهٔ فرمان‌های متنی Bash/sh/dash/zsh را با سقف ۶۵٬۵۳۶ نویسه و حداکثر چهار لایهٔ تو در تو از پوسته یا ابزار واسط مدل می‌کند. بازنویسی تنظیم Git با `-c` فقط برای `color.ui` و مقدارهای متنی `true`، `false`، `auto`، `always` یا `never` پذیرفته می‌شود. کلیدهای دیگر، نام‌ها یا مقداردهی‌های `GIT_CONFIG`/`GIT_CONFIG_*` در دستورهای داخلیِ مدل‌شدهٔ `export`، `declare`، `typeset`، `readonly` و `local`، همچنین `xargs` و عمل‌های اجرایی `find` مسدودند. این ابزار کمکی توسعه، رفتار برنامه‌های دلخواه را مدل نمی‌کند و جای مجوزدهی میزبان را نمی‌گیرد.

Storybook تنظیم مستقل Vite دارد، فایل محیط و کشف متغیر محیطی VITE را غیرفعال می‌کند، API قابلیت‌ها و کارخواه مشترک را کامل جایگزین می‌کند و تعامل و دسترس‌پذیری واقعی Chromium را با خطای متوقف‌کننده می‌سنجد. فایل محیط یا API واقعی لازم نیست. خروجی تولیدشده زیر `coverage` می‌ماند و ثبت نمی‌شود. محدوده و آستانهٔ پوشش محصول را حفظ کنید؛ خروجی مرورگر، LCOV واحد نیست.

ورودی برنامه، ترکیب App و Routes، ساخت production، مسیر Pact و provider، E2E برنامه، مقایسهٔ تصویر، اندازه‌گیری واقعی کارایی و اجرای استقرار واقعی کار آینده‌اند. بودجهٔ خالص و fixture عملیاتی ساختگیِ منتشرشده، بررسی مقدماتی هستند. پیش از ادغام پنل قابل اجرا، بررسی واقعی آن‌ها باید وارد دروازهٔ کامل برنامه شود. برای تنظیمات منتشرنشده، پرچم ساختگی برنامه تنظیم نکنید. [آزمون‌ها](testing.fa.md)، [مشارکت](../CONTRIBUTING.fa.md) و [ارزیابی درک](comprehension-evaluation.fa.md) را بخوانید.

## گسترش محدود پیش‌نیازها

فهرست اکنون ۴۳۶ فایل نگهداری‌شده در همان مرحلهٔ غیرقابل اجرا دارد. دوازده ورودی الزامی full و سیزده تعریف ثبت‌شده، مالکیت و ترتیب فرمان‌های خود را حفظ می‌کنند. فرمان npm عملیاتی یا پروفایل متمرکز تازه اضافه نشده است. مورد واحدِ ابزار خالص و مورد ساختگی تولید تنظیمات و بسته‌بندی و چرخهٔ Docker وارد همان دو فرمان پوشش می‌شود و گیت کامل را دوباره اجرا نمی‌کند.

استثناهای دقیق الگوی عمومی فقط `.env.example`، `deploy/docker/.env.example` و `deploy/native/hosts.env.example` با مقادیر ساختگیِ بازبینی‌شده‌اند. برای اعتبارسنجی کد، محیط محلی دلخواه را نخوانید. برخی CLIها فایل انتخاب‌شده را می‌خوانند، خروجی می‌نویسند یا درخواست شبکه می‌فرستند؛ در آزمون از API خالص و fixture صریح و ساختگی استفاده و برای عملیات واقعی مجوز دریافت کنید.

فقط اجرای درخت دقیق و نتیجهٔ واقعی آن شاهد آمادگی محلی است. فرادادهٔ تاریخی Win32، تنظیمات نسخه، ارزیابی سیاست یا fixture تولیدشده، artifact تولیدی، TLS مستقر، بازبینی تصویری فعلی یا نتیجهٔ واقعی Lighthouse را اثبات نمی‌کند.

آماده‌سازی اجراگرِ بررسی، هماهنگ‌سازی تصویر و Lighthouse و ثبت فرادادهٔ ساخت را بدون اثر هنگام import اضافه می‌کند. آزمون ساختگی، مالکیت منابع و پاک‌سازی هنگام شکست و منشأ را بدون راه‌اندازی برنامه، Chrome یا API می‌سنجد. فرمان npm عملیاتی ثبت نمی‌شود؛ گیت فعلیِ دوازده‌بررسی و الزام بازبینی انسانی تصویر تغییر نمی‌کنند. پذیرش CI برنامهٔ آینده جدا از workflow فعلی Linux آزموده می‌شود.
