# Assistant-neutral comprehension foundation

[English](ai-code-understanding.md) · [فارسی](ai-code-understanding.fa.md)

The guidance foundation supplies canonical English rules and skills, the AGENTS entry point, a machine task map, validation/settings/CI consistency checks with regressions, source-linked decisions and a read-only evaluation procedure. Human guides have complete English/Persian companions; active assistant instructions and evaluation prompts are English only. Guidance adds no AI runtime, vector database, indexer or cloud dependency to the application.

Read actual admitted capabilities and `applicationReady` from [the publication policy](../.github/bootstrap-policy.json), and required checks from [the manifest](../.agents/validation.json). Navigation must point to those admitted owners and distinguish source from evidence. While readiness is false, component/workshop evidence cannot establish an assembled application. When runnable capability is admitted, genuine application checks are still required; the declaration alone cannot prove E2E, reviewed images, performance or deployment.

Use targeted search and owning source, contracts and tests. Static maps cannot establish permissions, runtime session state or transactional behavior. A passing consistency check does not prove that a host loaded instructions, that an assistant understood them, or that guidance improved performance. Keep the source revision, unpublished-source fingerprint and uncertainty visible.

Optional Node/Bash hooks and host adapters require actual host support. They are development aids, not runtime dependencies or an authorization boundary. User instructions and existing authorization govern the task. Search/graph tools require a concrete need, access and measured benefit. Use the [evaluation procedure](comprehension-evaluation.md) and record actual results; configured scenarios are not completed experiments.

The task map also leads to admitted public release/deployment helpers and pure quality policies. Synthetic regressions belong to their registered measured suites; operational commands and required profiles must come from the manifest, never be inferred from prose. Read [deployment preparation](deployment.md), [performance policy](performance.md) and [visual provenance](visual-regression.md) for limits. Public examples are explicit synthetic sources; they do not permit reading real environments. Dated image metadata is history, not current execution or assistant comprehension evidence.
