# سیاست حفاظت شاخه

[English](branch-protection.md) · [فارسی](branch-protection.fa.md)

از بررسی‌های معمول GitHub CI، CodeRabbit و SonarQube Cloud استفاده کنید. سیاست
ادغام، نتیجهٔ CI و سرویس‌ها برای نسخهٔ فعلی، حداقل یک تأیید بررسی و حل گفت‌وگوها را
الزامی می‌کند. حفاظت باید شامل مدیران باشد، تأییدهای قدیمی را پس از تغییر کد کنار
بگذارد، به‌روز بودن شاخه را الزامی کند و ارسال اجباری و حذف شاخه را ممنوع کند.
مدیران مخزن تنظیمات واقعی سرویس را مدیریت می‌کنند.

مرحلهٔ پایه، **check** از CI، **SonarQube Cloud analysis** از GitHub Actions و
**SonarCloud Code Analysis** از خود سرویس را ارائه می‌کند. وضعیت معمول **CodeRabbit**
هم بخشی از سیاست بررسی است. نتیجهٔ واقعی و هویت سرویس ارائه‌دهنده را تأیید کنید؛
اضافه شدن workflow به معنی فعال شدن حفاظت نیست.

بررسی خودکار CodeRabbit غیرفعال است. فقط پس از
[پیش‌بررسی آخرین نسخه](../CONTRIBUTING.fa.md#پیش-از-درخواست-coderabbit) درخواست دستی
بدهید: تمام بررسی‌های الزامیِ غیر از خود CodeRabbit، scanner و دروازهٔ کیفیت واقعی
Sonar موفق باشند و کل گزارش مرتبط، در همهٔ شدت‌ها و کد قدیمی و جدید، صفر مسئلهٔ باز
یا حل‌نشده داشته باشد. شاهد غایب یا قدیمی و مثبت کاذبِ مستندشدهٔ باز مانع درخواست
است؛ کامیت جدید پیش‌بررسی را نامعتبر می‌کند. بررسی و تأیید خود CodeRabbit فقط برای
جلوگیری از چرخه کنار گذاشته می‌شود. مجوز، سهمیهٔ واقعی و نبود درخواست هم‌زمان تکراری
الزامی است. یافته‌های واقعی و تأیید بررسی را بخوانید؛
وضعیت موفق پیشرفت ممکن است مربوط به بررسی اجرا‌نشده باشد. تأیید خودکار پس از بررسی
کامل و بدون مشکل می‌تواند حد معمول تأیید را تأمین کند، اما شمارش عادی GitHub بررسی
سایر افراد واجد شرایط را هم می‌پذیرد و هویت یک ربات مشخص را الزام نمی‌کند.

این مرحله کارهای **build**، **e2e** و **visual** پنل کامل را ارائه نمی‌کند. الزامات
موجود برای آن‌ها همچنان مانع ادغام می‌مانند. فقط برای ادغام این مرحله آن‌ها را حذف،
جایگزین یا شبیه‌سازی نکنید. مرحلهٔ قابل اجرا باید شواهد واقعی برنامه را فراهم کند و
هر تغییر مجاز در حفاظت باید با نتایج واقعی میزبانی‌شده تطبیق داده شود.

نتیجهٔ واقعی و غیرهم‌زمان دروازهٔ کیفیت Sonar را علاوه بر اجرای scanner الزامی کنید.
شواهد مفقود، ناموفق، در انتظار، اجرا‌نشده یا محدودشده با سهمیه را بررسی کامل معرفی
نکنید. پیش از اعلام آمادگی ادغام، [راهنمای Sonar](sonarqube.fa.md) و
[راهنمای مشارکت](../CONTRIBUTING.fa.md) را بخوانید.
