# سیاست حفاظت شاخه

[English](branch-protection.md) · [فارسی](branch-protection.fa.md)

منبع مرحلهٔ application-verification کار واقعی build، e2e و visual را کنار نتیجه‌های بومی پیشین فراهم می‌کند. کار check مرجع تمام بررسی‌های پیشین را حفظ می‌کند. تنظیمات منبع شاهد اجرای میزبانی‌شده یا نصب حفاظت راه‌دور نیست.

تمام نوزده بررسی کامل مرجع در check اجرا می‌شوند و مجموعهٔ مستقل Storybook حفظ می‌شود. کارهای اختصاصی برنامه شاهد الزامی جدا اضافه می‌کنند؛ تست مرورگر یا مصرف‌کنندهٔ ساختگی، ارائه‌دهندهٔ واقعی API یا استقرار را ثابت نمی‌کند.

از بررسی‌های معمول GitHub CI، CodeRabbit و SonarQube Cloud استفاده کنید. سیاست
ادغام، نتیجهٔ CI و سرویس‌ها برای نسخهٔ فعلی، حداقل یک تأیید بررسی و حل گفت‌وگوها را
الزامی می‌کند. حفاظت باید شامل مدیران باشد، تأییدهای قدیمی را پس از تغییر کد کنار
بگذارد، به‌روز بودن شاخه را الزامی کند و ارسال اجباری و حذف شاخه را ممنوع کند.
مدیران مخزن تنظیمات واقعی سرویس را مدیریت می‌کنند.

بررسی‌های الزامی با مرحلهٔ منتشرشده هماهنگ‌اند. این پنج نتیجهٔ بومی پیشین را با شناسهٔ مشاهده‌شدهٔ برنامه حفظ کنید؛ نتیجه‌های واقعی build/e2e/visual برنامه فقط با تغییر مجاز و تأییدشدهٔ حفاظت راه‌دور پیش از ادغام پنل اجرایی اضافه می‌شوند:

| نتیجهٔ الزامی              | ارائه‌دهنده    | شناسهٔ برنامه |
| -------------------------- | -------------- | ------------- |
| `check`                    | GitHub Actions | `15368`       |
| `PR file limit`            | GitHub Actions | `15368`       |
| `SonarQube Cloud analysis` | GitHub Actions | `15368`       |
| `SonarCloud Code Analysis` | SonarCloud     | `12526`       |
| `CodeRabbit`               | CodeRabbit     | `347564`      |

تنظیمات واقعی سرویس و نتیجهٔ نسخهٔ فعلی را تأیید کنید؛ افزودن workflow یا نوشتن نام
یک بررسی در مستندات، حفاظت را فعال نمی‌کند. هنگام تغییر مجاز مرحله، حداقل تعداد
تأیید، اعمال حفاظت بر مدیران، کنار گذاشتن تأییدهای قدیمی، حل گفت‌وگوها، به‌روز بودن
سخت‌گیرانهٔ شاخه، تاریخچهٔ خطی و ممنوعیت ارسال اجباری و حذف را حفظ کنید.

بررسی خودکار CodeRabbit غیرفعال است. فقط پس از
[پیش‌بررسی آخرین نسخه](../CONTRIBUTING.fa.md#پیش-از-درخواست-coderabbit) درخواست دستی
بدهید: تمام بررسی‌های الزامیِ غیر از خود CodeRabbit، scanner و دروازهٔ کیفیت واقعی
Sonar موفق باشند و کل گزارش مرتبط، در همهٔ شدت‌ها و کد قدیمی و جدید، صفر مسئلهٔ باز
یا حل‌نشده داشته باشد. شاهد غایب یا قدیمی و مثبت کاذبِ مستندشدهٔ باز مانع درخواست
است؛ کامیت جدید پیش‌بررسی را نامعتبر می‌کند. بررسی و تأیید خود CodeRabbit فقط برای
جلوگیری از چرخه کنار گذاشته می‌شود. مجوز، سهمیهٔ واقعی و نبود درخواست هم‌زمان تکراری
الزامی است. یافته‌های واقعی و تأیید بررسی را بخوانید؛
وضعیت موفق پیشرفت ممکن است مربوط به بررسی اجرا‌نشده باشد. تأیید خودکار پس از بررسی
کامل و بدون مشکل می‌تواند حد معمول تأیید را تأمین کند، اما شمارش عادی GitHub بررسی
سایر افراد واجد شرایط را هم می‌پذیرد و هویت یک ربات مشخص را الزام نمی‌کند.

منبع برنامه کار بومی واقعی **build**، **e2e** و **visual** را فراهم می‌کند و check پروفایل کامل نوزده‌بررسی، شامل Storybook قبلی، را اجرا می‌کند. پیش از ادغام پنل اجرایی، موفقیت واقعی head فعلی را مشاهده و برای الزامی‌کردن هر سه نتیجهٔ بومی از GitHub Actions با شناسهٔ 15368 مجوز بگیرید؛ تمام حفاظت قبلی حفظ شود. مقایسهٔ تصویر به منشأ محیط اجرای همسان و تصویر تأییدشدهٔ انسانیِ دست‌نخورده نیاز دارد. بررسی ساختگی مصرف‌کننده یا مرورگر شاهد سازگاری ارائه‌دهندهٔ API یا استقرار نیست. کار ساختگی و موفقیت بررسیِ اجرا‌نشده شاهد آمادگی نیستند.

نتیجهٔ واقعی و غیرهم‌زمان دروازهٔ کیفیت Sonar را علاوه بر اجرای scanner الزامی کنید.
شواهد مفقود، ناموفق، در انتظار، اجرا‌نشده یا محدودشده با سهمیه را بررسی کامل معرفی
نکنید. پیش از اعلام آمادگی ادغام، [راهنمای Sonar](sonarqube.fa.md) و
[راهنمای مشارکت](../CONTRIBUTING.fa.md) را بخوانید.
