# نقشهٔ مستندات

[English](README.md) · [فارسی](README.fa.md)

انتشار `assistant-guidance` راهنمای محلی، مسیریابی وظیفه و روش ارزیابی را به محیط مؤلفه اضافه می‌کند و `applicationReady: false` را حفظ می‌کند. این سندها مالکیت منبع فعلی را توضیح می‌دهند و شاهد پنل قابل اجرا، استقرار یا ارزیابی انجام‌شدهٔ دستیار نیستند.
