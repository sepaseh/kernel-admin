The `core-auth` snapshot includes HTTP, session, localization and shared UI modules, plus providers, layouts and authentication screens. Usage describes prerequisites for a later application phase when route composition and the application entry point are admitted.

Keep documentation English, current and organized by reader goal. Update the owning guide instead of creating duplicate command inventories or dated status reports. Preserve localized product data and examples when their source is admitted.
