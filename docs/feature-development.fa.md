# توسعهٔ قابلیت پنل

[English](feature-development.md) · [فارسی](feature-development.fa.md)

از [نقشهٔ وظیفه](../.agents/navigation.json)، فرادادهٔ مسیر و قابلیت مالک آغاز کنید. ترکیب مجاز و `applicationReady` را از [سیاست انتشار](../.github/bootstrap-policy.json) و فرمان‌ها را از [فهرست مرجع](../.agents/validation.json) بخوانید. آمادگی false اجازهٔ ورودی برنامه نمی‌دهد و تغییر قابل‌اجرا به شاهد واقعی برنامه نیاز دارد. قرارداد HTTP، سیاست مجوز و تست را پیش از ویرایش بررسی کنید.

`src/shared` مستقل از app/features/layouts بماند. مؤلفهٔ Ant Design، توکن معنایی پوسته و آیکون نام‌دار مستقیم Lucide با اندازه و currentColor صریح و aria-hidden تزئینی را بازاستفاده کنید؛ کنترل مالک برچسب دسترس‌پذیر را می‌دهد. نوع را از دامنه یا کتابخانه مشتق کنید. نوع HTTP، مسیر و ابزار مخصوص قابلیت کنار مالک بماند؛ محدودیت مشترک نام پروفایل و نوع انتقال را بازاستفاده و پاسخ ناشناختهٔ توکن و تنظیمات را پیش از تغییر وضعیت اعتبارسنجی کنید.

نوع props نام‌دار و مؤلفهٔ نام‌دار `FC<Props>` با import صرفاً نوع از React تعریف کنید و قاعدهٔ مرجع React را رعایت کنید. جدول Ant Design فیلد را از رکورد سطر بخواند، نه اولین مقدار render. نسل نیت درخواست و نشست، لغو، تلاش مجدد دستی خواندن و محافظ تغییر داده حفظ شوند. یک بازپخش محافظت‌شدهٔ 401 واجد شرایط پس از refresh موفق در همان نسل، با تلاش مجدد دستی خواندن متفاوت است.

فرادادهٔ مسیر و دسترسی در `src/app/config/routes.ts` و `src/app/lib` هستند؛ API مستقل همچنان همهٔ عملیات را مجاز می‌کند. ترجمهٔ واقعی هر ده کاتالوگ تخت با همان ۱۱۱ پیام رشته‌ای ریشه و interpolation نگهداری شود. کلید معنایی را در هر زبان بازاستفاده و alias جایگزین‌شده را حذف کنید؛ محتوای مفقود را با fallback انگلیسی اجرا جایگزین نکنید. API مالک زبان فعال، جهت و تقویم است؛ مرورگر فقط پوسته و فشردگی را ذخیره می‌کند.

در کوچک‌ترین لایهٔ معنادار تست بنویسید و در صورت نیاز حالت دسترس‌پذیر Storybook اضافه کنید. تست ساختگی مؤلفه و HTTP شاهد مسیر کامل برنامه یا ارائه‌دهندهٔ واقعی نیست. مستندات مرتبط انگلیسی و فارسی و در تصمیم مهم ADR را به‌روز کنید. [اعتبارسنجی](validation.fa.md)، [قواعد React](../.agents/rules/react.md) و [قواعد نوع](../.agents/rules/typescript.md) را دنبال و پیش از commit یا تحویل PR با اجازهٔ صریح، دروازهٔ کامل را اجرا کنید.
