# ویژگی‌های کیفیت و شواهد

[English](quality-attributes.md) · [فارسی](quality-attributes.fa.md)

مرحلهٔ فعلی `assistant-guidance` مقدار `applicationReady: false` را حفظ می‌کند. هر ادعا را با منبع واقعی و بررسی اجراشده بسنجید.

| ویژگی         | شاهد فعلی و محدودیت                                                                                                                                                                                       |
| ------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| درستی         | تست واحد و React، ماژول منتشرشده را با HTTP ساختگی و fixture نسل نشست می‌سنجد. Chromium تعامل جداگانهٔ Storybook را بررسی می‌کند، نه مسیر کامل برنامه یا ارائه‌دهندهٔ واقعی را.                           |
| مالکیت        | نگهبان AST مرز منبع از قرارداد محلی، کاتالوگ تخت و راه‌انداز اجرا حفاظت می‌کند. API مستقل مالک اجرای احراز هویت، پایگاه داده، ذخیره‌سازی و فرادادهٔ زبان فعال است.                                        |
| دسترس‌پذیری   | ممیزی واقعی Storybook نقض را خطا می‌داند. بررسی صفحه‌خوان، مسیر صفحه‌کلید کل برنامه و مرجع تصویری بازبینی‌شده شاهد جداگانهٔ آینده یا دستی لازم دارند.                                                     |
| نگهداری‌پذیری | اعتبارسنجی مرجع، CI معنایی، بررسی مسیریابی و ارزیابی و تست راهنما از هماهنگی حفاظت می‌کنند. پیوند ایستا فهم را نشان نمی‌دهد.                                                                              |
| پوشش و امنیت  | LCOV واقعی واحد و راهبری، آستانهٔ پوشش بدون کاهش، audit وابستگی و Sonar بومی خطرهای متفاوتی را می‌سنجند. هیچ‌کدام نبود آسیب‌پذیری را ثابت نمی‌کند؛ استثنای منبع یا بررسی ضعیف‌تر نباید شکست را پنهان کند. |

شکست، انتظار، کنارگذاری، وضعیت توصیه‌ای و دستی را صریح گزارش کنید. بودجهٔ ساخت production، E2E برنامه، مقایسهٔ بصری، بازیابی عملیاتی و گردش‌کار CodeQL یا mutation در این مرحله منتشر نمی‌شوند. [اعتبارسنجی](validation.fa.md)، [محدودهٔ Storybook](storybook-verification.fa.md) و [ارزیابی درک](comprehension-evaluation.fa.md) را به کار ببرید؛ شاهد تاریخی یا مخزن دیگر را جای نتیجهٔ head فعلی نگذارید.
