# ADR 0001: زمان اجرای مستقل پنل

[English](0001-independent-runtimes.md) · [فارسی](0001-independent-runtimes.fa.md)

تاریخ: ۲۳ اکتبر ۲۰۲۶. وضعیت: پذیرفته‌شده.

به‌روزرسانی محدوده: ۲۷ اکتبر ۲۰۲۶. تصمیم پذیرفته‌شدهٔ زمان اجرای مستقل حفظ شده
است؛ مرحلهٔ منتشرشدهٔ `core-auth` مقدار `applicationReady: false` دارد.
ارائه‌دهنده‌ها، فرم‌های احراز هویت، ماژول‌های چیدمان، فرادادهٔ دسترسی و راهبری و
مالکان HTTP منتشر می‌شوند. نقطهٔ ورود React/Vite، ترکیب App و Routes، رابط
صفحه‌های کسب‌وکار، ساخت نهایی و مسیر مرورگر در مرحلهٔ بعد هستند.

پنل یک manifest بسته، lockfile، درخت سورس و تنظیم فرانت‌اند در ریشه دارد. نصب و
بررسی سورس به checkout دیگر یا انتشار بستهٔ داخلی نیاز ندارد. چرخهٔ ساخت و انتشار
آینده باید این استقلال را حفظ کند. هر قابلیت مالک نوع HTTP، مسیر و ابزار خود است؛
زیرساخت انتقال و نشست، قرارداد خالص مشترک و کاتالوگ کامل محلی مالک مشترک محلی
دارند. workspace، پیوند بستهٔ محلی یا وابستگی سورس به SDK بک‌اند اضافه نکنید.

API مستقل مالک اجرای احراز هویت، مجوزدهی، پایگاه داده، migration و ذخیره‌سازی است.
پنل آن را از HTTP با تنظیم عمومی صریح مصرف می‌کند. سازگاری قرارداد و ترتیب انتشار
آگاهانه همچنان الزام یکپارچه‌سازی است. وب‌سایت مستقل مالک مصرف‌کنندهٔ خود است.
این سند پنل، پیاده‌سازی یا استقرار فعلی هیچ‌کدام را تأیید نمی‌کند.
