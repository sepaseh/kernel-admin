# سندهای تصمیم معماری

[English](README.md) · [فارسی](README.fa.md)

این سندهای کوتاه دلیل تصمیم‌های پیاده‌شده‌ای را توضیح می‌دهند که از گراف فایل
یا import بازسازی نمی‌شود. شاهد استقرار سیستم production نیستند. منبع و قرارداد
فعلی و آزمون، رفتار را تعیین می‌کند؛ با تغییر تصمیم پذیرفته‌شده، پیامد را اصلاح
یا سند جایگزین اضافه کنید.

به‌روزرسانی محدوده: ۲۷ اکتبر ۲۰۲۶. این سندها به انتشار غیرقابل اجرای `core-auth`
با مقدار `applicationReady: false` مربوط‌اند. ارائه‌دهنده‌های Core، فرم‌های احراز
هویت، چیدمان‌ها و آداپتورهای HTTP منتشر می‌شوند؛ نقطهٔ ورود برنامه، ترکیب App و
Routes، رابط صفحه‌های کسب‌وکار، ساخت نهایی و مسیرهای مرورگر منتشر نمی‌شوند.
تاریخ‌های پذیرش اولیه تاریخی باقی می‌مانند. مسئولیت‌های API و وب‌سایت بیان مالکیت
و الزام یکپارچه‌سازی هستند و بررسی تازهٔ مخزن‌های مستقل محسوب نمی‌شوند.

برای انتخاب اثرگذار تازه، تاریخ و وضعیت، زمینه، تصمیم، مصالحه، ارجاع منبع و
بررسی و سند جایگزین‌شده را ثبت کنید. نسخهٔ اصلی انگلیسی و همراه کامل فارسی را
با هم نگه دارید. تمام جزئیات پیاده‌سازی را کپی نکنید، برای ویرایش عادی ADR
نخواهید و بستهٔ مدیریت تصمیم اضافه نکنید. مالک منتشرشده را در
[معماری](../architecture.fa.md)، [مالکیت HTTP](../http-client.fa.md)،
[مالکیت Core و احراز هویت](../core-auth.fa.md) و [بومی‌سازی](../localization.fa.md)
پیدا کنید. [راهنمای انتشار](../bootstrap.fa.md) و
[فهرست مرجع](../../.agents/validation.json) بررسی کامل فعلی را تعیین می‌کنند.
