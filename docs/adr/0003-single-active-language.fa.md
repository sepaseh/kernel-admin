# ADR 0003: یک زبان سیستم و کاتالوگ کامل

[English](0003-single-active-language.md) · [فارسی](0003-single-active-language.fa.md)

وضعیت: پذیرفته‌شده.

به‌روزرسانی محدوده: ۲۷ اکتبر ۲۰۲۶. انتشار `core-auth` مقدار
`applicationReady: false` دارد. ارائه‌دهنده‌های Core و Ant Design و فرم‌های احراز
هویت، مالکیت زبان کلاینت را طبق این سند پیاده می‌کنند؛ نقطهٔ ورود برنامه، ترکیب
App و Routes، صفحه‌های کسب‌وکار تنظیمات و تقویم و مسیر مرورگری زبان منتشر نشده‌اند.

یک زبان فعال ذخیره‌شده برای سیستم متعلق به تنظیمات API است. تغییر آن به مجوز مدیر
کل در API نیاز دارد. Core تنظیم عمومی را می‌خواند و فرم‌های احراز هویت زبان آن را
از راه‌انداز ترجمهٔ محلی مصرف می‌کنند. انتخابگر زبان بازدیدکننده، ترجیح زبان
مرورگر یا رویداد ذخیره‌سازی زبان اضافه نمی‌شود. مجوزدهی و ماندگاری API به بررسی
جداگانهٔ همان مخزن نیاز دارند؛ این سند شاهد استقرار آن سرویس نیست.

تا دریافت موفق تنظیم عمومی، آغاز کلاینت فارسی ثابت (`fa`) است. شکست اولیه آشکار و
قابل تلاش مجدد است؛ شکست بازخوانی آخرین تنظیم پذیرفته‌شده را نگه می‌دارد. بازخوانی
هنگام focus تغییر انجام‌شده در جای دیگر را دریافت می‌کند. i18next، Ant Design و
Day.js از فرادادهٔ پذیرفته‌شدهٔ API پیروی می‌کنند. فقط پوسته و حالت فشرده ترجیح
مرورگری با همگامی میان تب‌ها هستند.

مرز HTTP تنظیمات تمام فرادادهٔ زبان را اعتبارسنجی می‌کند. Core کد، جهت، تقویم و
نام‌های همان پاسخ را نگه می‌دارد. کد منطقه‌ای پشتیبانی‌شده به آداپتور کد پایهٔ
موجود نرمال می‌شود و سایر فیلدهای سرور جایگزین نمی‌شوند. دادهٔ نامعتبر خطای آشکار
دارد و دادهٔ آغازین جای پاسخ موفق قرار نمی‌گیرد. Ant Design و HTML جهت API و
Day.js تقویم API را مصرف می‌کنند. نگاشت محلی زبان کتابخانه را انتخاب و `gregorian`
را به نام `gregory` در Day.js تبدیل می‌کند؛ جهت یا تقویم را از روی کد حدس نمی‌زند.

رابط تنظیمات آینده باید کنترل زبان را به مدیر کل محدود و `languageCode` را از
درخواست تغییر پوسته و لوگوی ویرایشگر معمولی حذف کند. مجوزدهی فیلد در API همچنان
لازم است؛ پنهان‌کردن کنترل مجوزدهی نیست. رابط تقویم آینده باید از فرادادهٔ تقویم
API، از جمله تغییر فقط تقویم، پیروی کند و کلید میلادی `YYYY-MM-DD` در قرارداد را
با مالکان API هماهنگ نگه دارد. این مرحله نتیجهٔ صفحهٔ کسب‌وکار یا مرورگر را ادعا نمی‌کند.

ده کاتالوگ کامل تخت هم‌نام کد زبان با متن واقعی و interpolation یکسان را حفظ کنید.
fallback آغازین جای ترجمهٔ ناقص نیست. [Core](../../src/app/providers/core/Core.tsx)،
[i18next](../../src/shared/i18n/index.ts)، [بومی‌سازی](../localization.fa.md)،
[مالکیت HTTP](../http-client.fa.md)، [مالکیت Core و احراز هویت](../core-auth.fa.md) و
[سیاست انتشار](../bootstrap.fa.md) را بخوانید.
