# چرخهٔ خواندن درخواست

[English](request-lifecycle.md) · [فارسی](request-lifecycle.fa.md)

[useReadRequest](../src/shared/hooks/useReadRequest.ts) یک قصد خواندن را با شمارهٔ
ترتیب و AbortController مدیریت می‌کند. شروع خواندن بعدی، پذیرش دادهٔ جایگزین، تغییر
هویت منبع یا unmount کار قبلی را نامعتبر می‌کند. پاسخ قدیمی حتی اگر بارگذار signal
را نادیده بگیرد، دادهٔ جاری را بازنویسی نمی‌کند. لغو بارگذاری را بدون خطا تمام می‌کند؛
خطای واقعی نوسازی دادهٔ موفق قبلی را نگه می‌دارد.

[useReadResource](../src/shared/hooks/useReadResource.ts) این ابزار را به هویت تابع
بارگذار، وضعیت enabled و پاکسازی effect متصل می‌کند. مصرف‌کننده باید بارگذار را با
useCallback پایدار کند و همهٔ فیلترها و شناسه‌های مرتبط را در وابستگی‌هایش بگذارد.
signal داده‌شده را به خواندن HTTP قابلیت برسانید. reload منبع جاری را دوباره می‌خواند؛
replace نتیجهٔ تغییر را می‌پذیرد و خواندن قدیمی را نامعتبر می‌کند. منبع غیرفعال داده،
خطا یا وضعیت بارگذاری قدیمی نشان نمی‌دهد.

تست واقعی renderHook در React و jsdom جداگانه، تکرار effect در StrictMode، تغییر
فیلتر، لغو، unmount، جایگزینی و خطای دیررس را بررسی می‌کند. تست HTTP و نشست جداگانه
نسل حساب را بررسی می‌کند. این تست‌ها هوک و انتقال ساختگی‌اند و مرورگر یا صفحهٔ React
راه‌اندازی نمی‌کنند. [کلاینت HTTP](http-client.fa.md) مالک خطای انتقال و احراز هویت
است و ماژول هر قابلیت مسیر و واژگان DTO را دارد. این مسئولیت‌ها را از مؤلفه‌ها و
providerهای آینده مستقل نگه دارید.
