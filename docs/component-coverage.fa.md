# پوشش کامپوننت و پیش‌نیازها

[English](component-coverage.md) · [فارسی](component-coverage.fa.md)

برای سیاست و تبدیل خالص، آزمون واحد؛ برای چرخهٔ درخواست و provider، آزمون رگرسیون یکپارچه؛ و برای رفتار قابل مشاهدهٔ فرم، آزمون کامپوننت بنویسید. مرز پاسخ قدیمی، لغو، نسل نشست و مجوز را حفظ کنید. از آزمونی که فقط جزئیات پیاده‌سازی را تکرار می‌کند پرهیز کنید.

کارگاه ایزولهٔ Storybook داستان‌های ثبت‌شدهٔ احراز هویت، حساب، تقویم، تنظیمات، نقش و کاربر، ورودی و layout را با جایگزین کامل و ساختگی API، تعامل واقعی Chromium و audit مسدودکنندهٔ دسترس‌پذیری بررسی می‌کند. برنامهٔ سرهم‌شده یا API واقعی را اجرا نمی‌کند.

پیش‌نیازهای عملیات وارد مجموعه‌های پوشش موجود می‌شوند: سیاست bundle و Lighthouse، ورودی production و اعتبارسنجی مقصد در پوشش واحد؛ تولید تنظیمات، بسته‌بندی نسخه و منابع و راهبری Docker در پوشش governance قرار می‌گیرند. موارد تزریق‌شده و ساختگی، audit واقعی مرورگر، ساخت image یا مقصد مستقر را اثبات نمی‌کنند.

[فهرست مرجع](../.agents/validation.json) مالک هر ورودی الزامی، فرمان و ترتیب آن در مرحلهٔ اعلام‌شده است. پذیرش برنامه، بررسی‌های موروثی را حفظ و شاهد واقعی build، bundle، قرارداد مصرف‌کننده، مرورگر برنامه، تصویر بازبینی‌شده و Lighthouse را اضافه می‌کند. LCOV واحد و governance باید از همان snapshot دقیق کد به‌دست آیند. آستانه‌های پوشش و موارد فشار و مهلت موجود را حفظ کنید؛ هنگام توسعه کوچک‌ترین بررسی مرتبط و هنگام تحویل مجاز گیت کامل روی درخت دقیق را اجرا کنید.

آزمون یکپارچهٔ مسیر برنامه، providerها و router سرهم‌شده را با سرویس‌های ساختگی بررسی می‌کند. fixtureهای مرورگر مسیر کامل مصرف‌کننده را در همهٔ مرورگرهای پیکربندی‌شده بررسی و درخواست خارجی بدون handler را رد می‌کنند. بررسی مصرف‌کنندهٔ Pact، آداپتور HTTP واقعی کلاینت را مقابل mock provider محلیِ تحت مالکیت اجرا می‌کند؛ API مستقل را تأیید نمی‌کند. مقایسهٔ تصویری به سابقهٔ runtime منطبق و تصاویر تأییدشدهٔ واقعی انسان نیاز دارد. Lighthouse به build ساختگی production و پاک‌سازی مرورگر و preview تحت مالکیت نیاز دارد.

mutation، تأیید مستقل provider و بررسی استقرار روی مقصد مشخص به مالک پذیرفته‌شده و اجرای مشاهده‌شدهٔ جدا نیاز دارند. [آزمون](testing.fa.md)، [قرارداد](contract-testing.fa.md) و [سابقهٔ تصویری](visual-regression.fa.md) را ببینید.
