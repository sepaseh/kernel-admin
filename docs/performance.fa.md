# بررسی کارایی

[English](performance.md) · [فارسی](performance.fa.md)

برای تشخیص بررسی‌های مجاز ساخت، bundle و Lighthouse، [سیاست انتشار](../.github/bootstrap-policy.json)، [فهرست سورس](bootstrap.fa.md) و [گیت مرجع](../.agents/validation.json) همان revision را بخوانید. وجود ماژول کمکی و نام فرمان، برنامهٔ قابل اجرا یا نتیجهٔ موفق کارایی را ثابت نمی‌کند. سقف JavaScript همچنان ۴۵۰٬۰۰۰ بایت برای هر chunk و ۱٬۹۰۰٬۰۰۰ بایت در مجموع است. [ارزیاب bundle](../scripts/check-bundle-size.mjs) دارایی برنامه را جدا از خروجی Storybook اندازه می‌گیرد.

[سیاست خالص Lighthouse](../scripts/lighthouse-policy.mjs) مالک آستانه‌ها، ارزیابی گزارش و ساخت مقصد است. آزمون سیاست و چرخهٔ تزریق‌شدهٔ [اجراگرِ بدون اثر هنگام import](../scripts/run-lighthouse.mjs)، راه‌اندازی، قطع اجرا، پایان نوشتن گزارش و پاک‌سازی منابع متعلق به اجرا را می‌آزمایند. import اجراگر فرایندی راه نمی‌اندازد. آزمون ساختگی چرخه، ممیزی Lighthouse انجام نمی‌دهد؛ تا وقتی دروازهٔ انتشار بسته است، CLI باید اجرای برنامه را رد کند.

وقتی سیاست فعلی اجرای برنامه را مجاز می‌داند، ساخت کامل با تنظیمات عمومی ساختگی و صریح و preview محلی متعلق به اجرا را به کار ببرید. کشف فایل محیطی پیرامونی را غیرفعال کنید، درخواست خارجی غیرمنتظره را جدا نگه دارید و حافظه و گزارش تولیدشده را خارج از فهرست سورس نگهداری‌شده قرار دهید. راه‌انداز واقعی، آماده‌بودن تنظیمات، شرایط مرورگر و دستگاه و شبکه و مسیر گزارش را از همان revision بررسی کنید. شکست معیار، نوشتن گزارش یا پاک‌سازی منابع، بررسی را ناموفق می‌کند؛ باقی‌ماندن گزارش به معنی موفقیت نیست. بدون مجوز از مقصد واقعی API استفاده نکنید.

آداپترهای مشاهده‌پذیری و آزمون‌های منتشرشده فقط رفتار رویداد و حریم خصوصی در دامنهٔ خود را توصیف می‌کنند، نه کارایی میدانی جمع‌آوری‌شده. از وجود کد آداپتر، ترافیک، دسترس‌پذیری، صدک کاربران یا collector فعال نتیجه نگیرید. گزارش واقعی به سرویس پیکربندی‌شده و دارای مجوز و سیاست مستقل حریم خصوصی، نگهداری و تجمیع نیاز دارد.

برای هر نتیجهٔ اجراشده، revision بررسی‌شده، runtime، نخستین شکست و محدودیت‌ها را ثبت کنید. اندازه‌گیری آزمایشگاهی نتیجهٔ میدانی نیست؛ آستانه‌ها، throttling و بودجه‌ها نباید برای پنهان‌کردن رگرسیون بازتر شوند. بررسی کارایی روی ارائه‌دهندهٔ واقعی API و نسخهٔ مستقر به مقصدهای دارای مجوز مستقل نیاز دارد.

[آزمون](testing.fa.md) و [استقرار](deployment.fa.md) را ببینید.
