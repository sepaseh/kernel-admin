# مدل تهدید ادمین

[English](threat-model.md) · [فارسی](threat-model.fa.md)

دارایی‌ها شامل اطلاعات bearer در حافظه، عملیات دارای امتیاز، دادهٔ پروفایل، پاسخ HTTP و artifact تغییرناپذیر آیندهٔ انتشارند. مرزها میان ورودی نامطمئن مرورگر، مالک‌های محلی HTTP و نشست ادمین، API با مجوز مستقل، origin رسانهٔ بیرونی و میزبانی ایستا و TLS آیندهٔ اپراتور قرار دارند. منو و فرادادهٔ مسیر، مجوز نیستند؛ API دسترسی را اعمال می‌کند.

رندر امن، اعتبارسنجی runtime پاسخ حساس، origin صریح، حفاظت نسل و نیت درخواست و خطای سازگار با حریم خصوصی را حفظ کنید. تغییر توکن و cookie، CSRF و origin و پروتکل ناسازگار باید با مالک API هماهنگ شود. کاتالوگ محلی است؛ زبان، جهت و تقویم در اختیار تنظیمات سرور می‌مانند. تنظیمات مرورگر فقط انتخاب تم و compact را ذخیره می‌کند.

مقادیر عمومی ساخت و نمونه‌های ساختگی نباید راز داشته باشند. اعتبارسنجی بسته‌بندی و مسیر و الگوهای Nginx، خطرهای مشخصِ آماده‌سازی را کاهش می‌دهند؛ ساخت واقعی، گواهی مورد اعتماد، استقرار امن یا artifact بدون راز را اثبات نمی‌کنند. اجرای آیندهٔ اپراتور مجوز و شاهد مستقل لازم دارد.

آزمون فعلی از دادهٔ ساختگی ایزوله و mock کامل استفاده می‌کند. پایگاه داده، upload، محیط واقعی و production خارج از fixture هستند. برای هر کنترل، کد و آزمون و خطر باقی‌مانده را ثبت کنید. چرخش اعتبارنامه، محدودیت نرخ توزیع‌شده، بازیابی یا سخت‌سازی استقرارِ مطلوب را پیاده‌سازی‌شده معرفی نکنید.
