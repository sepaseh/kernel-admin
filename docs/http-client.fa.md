# کلاینت HTTP و تنظیمات سرور

[English](http-client.md) · [فارسی](http-client.fa.md)

[مرحلهٔ انتشار](bootstrap.fa.md) که هنوز پنل قابل اجرا نیست، انتقال Axios و هفت مالک
HTTP را ارائه می‌کند: احراز هویت، حساب، نقش‌ها، کاربران، تنظیمات، تقویم و بارگذاری
لوگوی تنظیمات. تایپ‌های محلی قرارداد HTTP هستند و پیاده‌سازی سرور نیستند. اجرای احراز
هویت، دیتابیس و ذخیره‌سازی متعلق به API مستقل است. SDK بک‌اند، checkout دیگر یا
فهرست صادرات رابط کاربری وارد نمی‌شود.

## مرز انتقال

[config.ts](../src/shared/api/config.ts) در صورت تعیین از VITE_API_BASE_URL و در غیر
این صورت از مبدأ مرورگر استفاده می‌کند. این تنظیم عمومی فرانت‌اند است و نباید حاوی
اطلاعات محرمانه باشد. تست‌ها کشف فایل محیطی را غیرفعال می‌کنند و پیش از بارگذاری
کلاینت نشانی ساختگی می‌دهند.

[client.ts](../src/shared/api/client.ts) از Axios نصب‌شده، ارسال credentials، زمان
انتظار ۱۵ ثانیه و AbortSignal صریح استفاده می‌کند. کلید JSON درخواست snake case و
پاسخ camel case می‌شود. FormData و پاسخ باینری هویت خود را حفظ می‌کنند. متدهای DTO
جنریک فقط در همین مرز HTTP شکل اعلام‌شدهٔ قرارداد را فرض می‌کنند؛ تبدیل کلیدها
unknown برمی‌گرداند و اعتبارسنجی شکل داده نیست. پاسخ احراز هویت و تنظیمات برنامه
پیش از تغییر وضعیت نشست یا برنامه در زمان اجرا اعتبارسنجی می‌شوند.

خطا پیام غیرخالی API و cause ساختاری را نگه می‌دارد یا پیام ترجمه‌شدهٔ timeout،
شبکه یا خطای غیرمنتظره می‌دهد. فقط شناسهٔ درخواست با قالب امن و طول محدود نگهداری
می‌شود. لغو همچنان لغو Axios است. اطلاعات ورود و payload ثبت نمی‌شوند.

## مالکیت نشست

هر عملیات محافظت‌شده هنگام فراخوانی متد کلاینت نسل نشست را هم‌زمان می‌گیرد. اگر
پیش از اجرای صف Axios ورود یا خروج نسل را تغییر داده باشد، interceptor پیش از ارسال
payload آن قصد قبلی را لغو می‌کند. هر متد پس از پایان Axios و پیش از تبدیل کلید یا برگرداندن داده دوباره همان نسل را بررسی می‌کند. ورود و ثبت‌نام نیز پیش از ذخیرهٔ توکن نسل را بررسی می‌کنند. موفقیت، ۴۰۱ و نوسازی دیررس حساب قدیم روی حساب جدید اثر نمی‌گذارند. خواندن عمومی GET/HEAD تنظیمات به نشست وابسته نیست.

۴۰۱ محافظت‌شده در هر نسل یک نوسازی مشترک و حداکثر یک تکرار دارد. نوسازی نسل را
تغییر نمی‌دهد؛ ورود و خروج آن را نامعتبر می‌کنند. لغو یک منتظر، نوسازی مورد نیاز
منتظر دیگر را لغو نمی‌کند. خطای گذرا و پاسخ نوسازی نامعتبر امکان تلاش مجدد را حفظ
می‌کنند. ۴۰۱/۴۰۳ قطعی نوسازی و ۴۰۱ تکرار فعلی نشست جاری را یک بار منقضی می‌کنند.
۴۰۱ بدون نسل مشخص اجازهٔ پاک‌کردن نشست ندارد. ورود، ثبت‌نام و نوسازی پیش از ذخیره،
توکن رشته‌ای غیرسفید را بررسی می‌کنند. خروج در نسل آغازکننده یکسان‌سازی می‌شود و
نشست ورود جدید را پاک نمی‌کند.

## تنظیمات متعلق به سرور

[settings/api.ts](../src/features/settings/api.ts) کل پاسخ تنظیمات، هر دو پالت هفت
فیلدی و رکورد اختیاری لوگو را بررسی می‌کند. رشتهٔ خالی رنگ برای تنظیم پیش‌فرض آتی
مجاز است. [قرارداد ظاهر](../src/shared/contracts/appearance.ts) فقط واژگان خالص است
و Ant Design یا رنگ پیش‌فرض را راه‌اندازی نمی‌کند. راه‌انداز پوستهٔ آینده باید همین
قرارداد را وارد کند و شکل پالت دیگری نسازد.

هر زبان کد پشتیبانی‌شده، جهت صریح ltr/rtl، تقویم صریح gregorian/jalali و نام عمومی و
بومی غیرسفید دارد. کد منطقه‌ای به کاتالوگ ثبت‌شده نرمال می‌شود؛ جهت، تقویم و نام‌ها
حتی در صورت تفاوت با عرف کد، عین پاسخ سرور می‌مانند. فرادادهٔ ناقص یا پشتیبانی‌نشده
خطای کنترل‌شدهٔ ترجمه‌شده می‌دهد. حدس زبان مرورگر، ترجیح زبان در localStorage و جدول
ثابت جهت نداریم. فقط مدیر کل زبان فعال سرور را تغییر می‌دهد.

## شواهد و محدودیت

تست‌های مالک مسیر، متد و payload، درخواست Axios واقعی با MSW نصب‌شده، تبدیل کلید،
بایت فایل چندبخشی، رقابت نوسازی، پاسخ نامعتبر، مرجع بودن زبان سرور و لغو را می‌سنجند.
ارسال باینری با adapter مربوط به Axios و Blob واقعی نیز آزموده می‌شود. MSW 3 با
onUnhandledFrame:error شبکهٔ اعلام‌نشده را رد می‌کند. همهٔ پاسخ‌ها و اطلاعات ورود
ساختگی‌اند و API در حال اجرا یا سرویس تولید تماس نمی‌گیرد. این شواهد انتقال است؛
شاهد کوکی مرورگر، مجوز سرور، پنل کامل یا اتصال تولید نیست.
[چرخهٔ درخواست](request-lifecycle.fa.md) و
[اعتبارسنجی کامل](../CONTRIBUTING.fa.md) را رعایت کنید.
