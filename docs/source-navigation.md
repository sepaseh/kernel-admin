The listed test files identify where to investigate and extend coverage. Read their actual assertions and current results before drawing conclusions about behavior. [Testing](testing.md) distinguishes synthetic fixture, browser, visual and provider evidence.

Keep password/filter helpers with users, logo upload helpers with settings and permission contracts with roles. Cross-feature profile limits belong in [shared contracts](../src/shared/contracts/index.ts); transport types belong in `src/shared/api`. Use local source and public types rather than another repository's implementation.

For repository work, follow [AGENTS](../AGENTS.md), [the Git router](../.agents/rules/git.md) and [Contributing](../CONTRIBUTING.md). Operational helper CLIs can write files, start resources or contact a target; read them before execution and use only synthetic fixtures for source checks.
