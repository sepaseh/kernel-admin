# مالکیت کاتالوگ و زمان اجرای محلی

[English](localization.md) · [فارسی](localization.fa.md)

[مرحلهٔ http-lifecycle](bootstrap.fa.md) کاتالوگ‌های کامل محلی و راه‌اندازهای
واقعی ترجمه و تاریخ را منتشر می‌کند. آزمون‌ها وابستگی‌های نصب‌شدهٔ واقعی را در Node
اجرا می‌کنند. applicationReady:false آگاهانه حفظ می‌شود؛ پنل قابل اجرا، اتصال provider تنظیمات یا مسیر مرورگر در این مرحله منتشر نشده است؛ اتصال HTTP تنظیمات وجود دارد.

## یک کاتالوگ کامل برای هر زبان

[src/shared/i18n/locales.ts](../src/shared/i18n/locales.ts) مالک ده کد ar، de، en، es،
fa، fr، it، pt، ru و tr است. هرکدام دقیقاً یک شیء در locales/<code>.ts با ۱۱۰ پیام
رشته‌ای غیرخالی در ریشه دارند. [catalogs.ts](../src/shared/i18n/catalogs.ts) همان اشیا
را ثبت می‌کند؛ آن‌ها را کپی نکنید و پوشش سازگاری نسازید. کلیدهای معنایی ریشه را
دوباره استفاده کنید، نام متغیرهای i18next مانند {{variable}} و ترجمه‌های واقعی را
حفظ کنید. شیء تودرتوی common، پیشوند common.، فایل جداگانهٔ admin/common، پوشهٔ هر
زبان، spread انگلیسی یا جای‌نگهدار fallback مجاز نیست. کاتالوگ انگلیسی شکل کلید
TranslationCatalog را تعیین می‌کند؛ این نوع در زمان اجرا حذف می‌شود.

برگ‌های کاتالوگ، locales.ts و [dayjs/fa.ts](../src/shared/i18n/dayjs/fa.ts) فقط تایپ
محلی کاملاً حذف‌شونده وارد می‌کنند. واردسازی جایگزین اجرایی، بازصادرات، واردسازی
پویا یا require ممنوع است. فقط catalogs.ts اشیای مرجع کاتالوگ را بارگذاری می‌کند.
داده نمی‌تواند بسته یا راه‌انداز اجرایی وارد کند. API و وب‌سایت مستقل مالک سورس
خود هستند و هیچ‌کدام وابستگی اجرایی این پروژه نیستند.

## راه‌اندازی ترجمه و مرجع تنظیمات

[index.ts](../src/shared/i18n/index.ts) مالک راه‌اندازی i18next/react-i18next با
کاتالوگ‌های واقعی محلی و راه‌اندازی و fallback ثابت فارسی است. بارگذاری ماژول
منتظر پایان راه‌اندازی می‌ماند تا مصرف‌کننده موتور آماده دریافت کند. ترجیح زبان مرورگر
را نمی‌خواند یا ذخیره نمی‌کند. React وابستگی اجرایی افزونهٔ ترجمه است، ولی صفحه‌ای
منتشر نشده است. کلید گمشده هویت خود را حفظ می‌کند و پیام تشخیصی می‌دهد؛ fallback
نبود ترجمه را توجیه نمی‌کند.

[language.ts](../src/shared/config/language.ts) پیشوند کدهای ثبت‌شده و گونه‌های
منطقه‌ای را نرمال می‌کند. این کار فقط انتخاب کاتالوگ است؛ جدول جهت یا تقویم نداریم.
زبان فعال، جهت، تقویم و نام عمومی و بومی متعلق به API هستند؛ فقط مدیر کل می‌تواند
زبان فعال را تغییر دهد. [آداپتر HTTP تنظیمات](http-client.fa.md) تمام فرادادهٔ سرور را اعتبارسنجی و حفظ می‌کند و خطای ترجمه‌شده می‌دهد. فرادادهٔ ناقص یا پشتیبانی‌نشده به حدس جهت یا تقویم محلی منجر نمی‌شود. این مرحله اتصال provider، انتخابگر زبان بازدیدکننده یا اتصال مرورگر را پیاده نمی‌کند. ترجیح پوسته و فشردگی مستقل است.

[تابع پیام خطا](../src/shared/lib/error.ts) پیام Error واقعی را نگه می‌دارد و برای
سایر مقادیر پرتاب‌شده پیام unexpectedError موتور ترجمهٔ فعال را می‌گیرد. وجود
فیلد message در یک شیء دلخواه به معنی معتبر بودن آن نیست.

## ثبت تاریخ

[date.ts](../src/shared/i18n/date.ts) نه زبان کتابخانهٔ Day.js را همراه با دادهٔ محلی فارسی و
افزونهٔ Jalaliday ثبت می‌کند. نام فروشندهٔ انگلیسی en-gb است. ثبت، نام محلی ماه‌های
تقویم فارسی را اضافه می‌کند و زبان یا تقویم فعال را عوض نمی‌کند. مصرف‌کننده تقویم
انتخاب‌شده در API را صریح انتخاب می‌کند؛ این ماژول آن را از کد زبان حدس نمی‌زند.
ماه‌های میلادی months و جلالی jmonths در دادهٔ خالص فارسی متمایز می‌مانند.

آزمون با بستهٔ واقعی، ثبت نه زبان کتابخانه و دادهٔ محلی فارسی، سال میلادی و جلالی، نام‌های غیرخالی و متفاوت
ماه و دوازده نام یکتای ماه تقویم فارسی را بررسی می‌کند. برچسب فارسی سپتامبر میلادی
و شهریور جلالی مستقیم بررسی می‌شوند. زبان مرورگر یا سیستم‌عامل زبان فعال را تعیین
نمی‌کند.

## اعتبارسنجی و شواهد

تست کاتالوگ، کامل بودن کلیدهای ریشه، متغیرها، هویت مرجع، واردسازی خالص و AST دادهٔ
ثابت را بررسی می‌کند. تست راه‌انداز از موتور واقعی، هر ده کاتالوگ، fallback ثابت،
جاسوس حافظهٔ ساختگی و نرمال‌سازی کد استفاده می‌کند. کنترل مرز فقط مسیرهای صریح بستهٔ
راه‌انداز در همین checkout را مجاز می‌داند و قرارداد و داده خالص می‌مانند. هر ماژول
اجرایی جدید در پوشش واقعی و تحلیل سورس، امنیت و تکرار حضور دارد؛ فقط ده فایل ثابت
دادهٔ زبان همان استثنای مجاز قبلی CPD را دارند.

ابتدا npm ci و سپس npm run validate -- full را اجرا کنید. هر نه بررسی مرجع در هر
PR، مستقل از مسیر تغییرکرده اجرا می‌شود؛ کشف فایل محیط غیرفعال است و LCOV واقعی از
همین checkout می‌آید. [پیش‌بررسی Sonar](sonarqube.fa.md) را رعایت کنید. شواهد مؤلفه،
اتصال provider، ساخت نهایی، مرورگر، دسترس‌پذیری و تصویر باید پیش از ادغام هر پنل
قابل اجرا به بررسی کامل مرجع اضافه شوند.

اعتبارسنجی واقعی فرادادهٔ کامل در [مالک تنظیمات HTTP](http-client.fa.md) منتشر شده است. کد پشتیبانی‌نشده، جهت یا تقویم مفقود و نام ناقص خطا می‌دهند؛ داده از ترجیح مرورگر حدس زده نمی‌شود. اتصال provider و پنل هنوز در این مرحله نیست.
